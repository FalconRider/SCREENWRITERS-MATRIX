# SCREENWRITERS-MATRIX   SMX  2026 V4  - a work  in progress

Ai  Story Generator  - Tagline,  to  detailed 27 scene Outline  for screenplay development.

Api and Token Free   - must have existing free account on ANY Ai engine.

You  download  and click on the html file to open an entry screen.

You enter a few dramatic elements, main character, setting conflict etc  on an HTML template

You  push  GENERATE.

-this causes an agentic -like prompt to be generated, wit all the mechanical bits you'll need 
and copied to your clipboard
-also shows on template ,  you don't even have to read it.

You open Grok or Claude or ChatGPT or your fav Ai.

You click CTL V  in the prompt box  and hit ENTER.
